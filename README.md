# Guinea Pig Mod

Adds a cute Guinea Pig mob with 4 variants to Minecraft

## Features

- Adds a new Guinea Pig mob with 4 variants
- Each variant has unique textures
- Guinea Pigs spawn naturally in the world

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.11 or later
- Fabric API

## Installation

1. Download the mod JAR file from the releases page
2. Place the JAR file in your `mods` folder
3. Launch Minecraft with the Fabric profile

## Usage

Once installed, Guinea Pigs will spawn naturally in the world. You can find them in grassy biomes.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
